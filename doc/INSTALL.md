# project-snapshot-generator

Generates a complete textual snapshot of a project's source code and directory structure for LLM consumption.


## Install from PYPI

The homepage in pipy is https://pypi.org/project/project_snapshot_generator/

```bash
pip install --upgrade project_snapshot_generator
```

Using:

```bash
project-snapshot-generator
```

## Install from source
Installing `project-snapshot-generator` program

```bash
git clone https://github.com/trucomanx/ProjectSnapshotGenerator.git
cd ProjectSnapshotGenerator
pip install -r requirements.txt
cd src
python -m build
pip install dist/project_snapshot_generator-*.tar.gz
```
Using:

```bash
project-snapshot-generator
```

## Uninstall

```bash
pip uninstall project_snapshot_generator
```
